# NLP-Research-Paper-Intelligence-System
The NLP Research Paper Intelligence System is an AI-powered application that helps users search research papers using semantic similarity. It retrieves the most relevant papers and provides topic classification, named entity recognition, summarization, readability analysis, and keyword extraction.


## Features
- Semantic Search using Sentence Transformers + FAISS
- Research Paper Retrieval
- Automatic Text Summarization
- Keyword Extraction using KeyBERT
- Topic Classification
- Named Entity Recognition (NER)
- Readability Score Analysis


## Technologies Used
- Python
- Google Colab
- Sentence Transformers
- FAISS
- Hugging Face Transformers
- spaCy
- KeyBERT
- TextStat
- Pandas
- NumPy

## Installation
git clone <repository link>

cd NLP-Research-Paper-Intelligence-System

pip install -r requirements.txt

Run the notebook in Google Colab or Jupyter Notebook.

Open the notebook
Run all cells
Enter a research topic
Example:
Deep learning in medical imaging
The system will display
Semantic Search Results
Topic Classification
Named Entities
Summary
Readability Score
Keywords
